NoomiClone Bedrock add-on (minimal)

Files:
- behavior_pack/ (manifest + entities/items/blocks + loot_tables)
- resource_pack/ (manifest + models + textures)

How to use:
1) Download ZIP of this repo on your iPhone (Download -> Open in Files).
2) In Files, unzip and rename the .zip to NoomiClone.mcaddon (or create a zip containing behavior_pack and resource_pack and rename to .mcaddon).
3) Tap NoomiClone.mcaddon -> Open in Minecraft. It will import the packs.
4) In Minecraft, enable the resource and behavior packs for a new world (and Experimental Gameplay if needed).
5) Test: in chat use: /give @s noomi:clone_core 1

Note: textures are provided as base64 files (clone_core.png.base64). You can decode them using an online decoder to get real PNGs if needed.
